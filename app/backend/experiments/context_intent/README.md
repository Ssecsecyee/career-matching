# 문맥 분류 고정 QA 사례

cases.json은 21개 합성 평가 사례의 초기 정답 라벨이다. 실제 DB/대화/수집 원문이 아니다. 동일 문구를 다른 문맥으로 비교한다. context_hint는 전체 요청 재현용 스냅샷이 아니므로 실제 모델 평가 때 선택 공고·검색 조건·교육 목록을 통제된 합성 상태로 보완해야 한다.

현재 테스트는 계약과 서버 분기를 모의 출력으로 검증한다. 이 라벨만으로 Sonnet 정확도를 측정했다고 해석하지 않는다. 이후 동일 조건에서 Sonnet/소형 모델의 target·action 정확도, 변경 필드 보존율, 확인 필요 사례의 오실행률, JSON 유효율, 지연·토큰 사용량을 비교한다. live 호출 도구는 이번 변경에 자동 실행으로 넣지 않았다.
