# 규칙 판단 기록부

추출·표준화·라벨링·추천 **규칙을 정하거나 바꾼 판단**을 한 줄씩 남긴다. 무엇을 물었고, 어떤 선택지가 있었고, 누가 정했고, 수치가 어떻게 바뀌었는지. 자세한 이유는 링크한 노트에 있다. 이 표에 없는 규칙 변경은 하지 않는다 (AGENTS.md).

- 결정자: **사용자** = 승현님이 채팅으로 정함 · **AI 제안 → 사용자 승인** · **AI 판단(확인 대기)** = 사용자 확인 전, 뒤집힐 수 있음
- 수치는 항상 기준(정답셋 승인 여부, 공고 수)을 같이 적는다.
