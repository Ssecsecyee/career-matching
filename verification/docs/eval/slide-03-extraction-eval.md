# 슬라이드 03 — 기술 추출 평가: 모델과 검사 코드를 고정

> 20개 공고의 자격요건·우대사항 228줄을 사람이 검토한 정답과 비교했다.

## 1. 평가 데이터
| 항목 | 값 | 근거 |
|---|---|---|
| 공고 | **20건**: 점핏 백엔드 실제 채용공고 | 팀원 DB 스냅샷 |
| 조건 줄 | **228줄**: 자격요건·우대사항을 조건 문장으로 나눔 | 친구 코드(`condition-split-v3`)가 나눈 결과를 그대로 씀 |
| 봉인 | 2026-11-17 11:31 | [[v3v4-results]] §1 |

## 2. 정답 작성 원칙
| 원칙 | 내용 |
|---|---|
| 기술명 기준 | 경험 설명 전체를 쓰지 않고 구체적인 기술 이름을 적는다 |
| 원문 보존 | 원문에 실제로 나온 표기를 그대로 쓴다 |
| 비기술 제외 | 소통 능력 같은 일반 역량은 기술 이름으로 만들지 않는다 |

- **정답을 만든 방식:** GPT가 초안을 달고, 사람이 228줄을 모두 검토했다.
  - 60줄(27%)을 고쳤다.
  - 7줄은 사람이 처음부터 달았다.
- 정답 기준은 사용자가 정했다. 기준 문서는 [[labeling-guide]]의 V3·V4 절이다.

## 3. 통제된 A/B 비교
| | 기존 프롬프트 (B) | 개선 프롬프트 (C) |
|---|---|---|
| 모델 | Claude Sonnet 4.6 (Bedrock) | 같음 |
| 검사 코드 | 친구의 원래 검사 코드 (기술 이름은 원문 그대로여야 함) | 같음 |
| 입력 | 같은 228줄, 3줄씩 묶어 83회 호출 | 같음 |
| 다른 점 | — | 시스템 프롬프트에 `eval/prompts/c_rules.md`(기술 추출 규칙)를 덧붙임 |

**바뀐 것은 기술 추출 규칙뿐이다.**

## 4. 예시 — 기존 프롬프트가 기술 이름 칸에 넣은 것
기존 프롬프트(B)의 실제 출력에서 확인한 예다. 공고 원문은 git에 올리지 않으므로 모델이 낸 용어만 적는다.

| 기존(B)이 기술 이름으로 낸 것 | 문제 |
|---|---|
| "의사소통", "협업", "개발 리딩" | 비기술 역량이다 |
| "프로젝트 관리 경험", "성공한 프로젝트 경험" | 경험 설명이다 |
| "API 구현", "클라우드 환경 개발 경험" | 문장을 줄인 구절이다. 원문에 그대로 없어서 검사에서 떨어졌다 |

- **원문에 글자 그대로 없는 이름의 수:** B는 80개(12건), C는 2개(2건)였다.
- ⚠️ **슬라이드의 "Spring Boot 기반 서비스 개발 경험 → 서버 개발 역량"은 설명용으로 만든 예시다.** 실제 B 출력에는 "서버 개발 역량"이 없다.
  - 실제 사례만 쓰려면 위 표의 용어로 바꾼다.
  - 그대로 쓰려면 슬라이드에 "(예시)"라고 표시한다.

## 5. 결과 (다음 슬라이드용)
**서비스 기준**: 친구의 검사에서 떨어진 공고는 결과 없음으로 센다. 이 기준은 결과를 보기 전에 정했다.

| | B | C | C − B | 95% 구간 (공고 단위 부트스트랩) |
|---|---|---|---|---|
| 검사 통과 공고 | 7 / 20 | **17 / 20** | | |
| 기술 이름 F1 (공고별 평균) | 0.114 | **0.487** | **+0.373** | 0.223 ~ 0.520 |
| 범주 정확도 | 0.149 | 0.487 | +0.338 | 0.177 ~ 0.492 |

**답의 질만 볼 때**: 범주를 무시하고, 이름이 서로를 포함하면 맞은 것으로 친다.
- F1: B 0.549 → C 0.674 (+0.125, 95% 구간 0.10 ~ 0.15)

**발표 문장**
> 규칙을 붙이면 형식 검사 통과가 20건 중 7건에서 17건으로 늘어, 서비스에 나가는 결과가 크게 늘었다(F1 0.11 → 0.49). 형식 문제를 빼고 답의 질만 봐도 0.55 → 0.67로 좋아졌다(+0.12, 95% 구간 0.10~0.15).

## 6. 함께 밝힐 한계
- **정답:** 사람이 처음부터 단 것이 아니다. GPT 초안을 사람이 검토했다.
  - 정답 기준과 C 규칙을 같은 사람이 정했다. 따라서 이 결과는 "기준을 알려 주면 모델이 그 기준에 맞춘다"는 뜻이다.
- **실행 횟수:** B와 C를 한 번씩만 실행했다.
- **데이터:** 공고 20건, 출처는 점핏 하나, 직무는 백엔드뿐이다.
- **절대 점수:** C도 기술 이름 F1이 0.49~0.57로, 강의 기준 0.7에 못 미친다.
- **검증 경로:** 이 평가는 운영에서 꺼져 있는 배치 기술 추출 경로를 대상으로 했다. 운영에는 반영되지 않았다.
- **비용:** 약 3.9 USD
