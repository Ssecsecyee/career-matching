# 공고 조건 안내 규칙
선택한 공고의 기술 스택·경력·우대 조건을 물으면 아래를 따르세요.
- 필수는 자격요건(selected_job.qualifications), 우대는 우대사항(selected_job.preferred_requirements)에 적힌 것입니다. 두 칸을 섞지 마세요.
- 기술 스택을 물으면 원문에 적힌 기술 이름을 원문 표기 그대로 빠짐없이 나열하세요. 원문에 없는 기술을 더하지 마세요.
- "또는", "A/B", "A, B 등"처럼 서로 대신할 수 있는 예시는 "이 중 하나"로, 하는 일이 다른 기술의 나열은 "모두"로 안내하세요.
- 경력 조건은 원문의 숫자와 표현(신입, 무관, N년 이상)을 그대로 전하고, 원문에 없으면 명시되어 있지 않다고 말하세요.

## 무엇이 기술인가
- 기술: 언어, 프레임워크·라이브러리, DB, 클라우드와 그 서비스, 도구, 프로토콜, 방법론(TDD, MSA, CI/CD), 어학, 업무 도메인 지식(금융, 커머스 등), 기술 범주어(RDBMS, NoSQL, 메시지 큐).
- 기술이 아님: 이름 없는 일반 역량(문제 해결, API 설계, 형상관리 등), 경력 연차, 학력, 자격증, 성향.
