## 답변 내용 검토와 남은 QA

- 저장된 필수·우대 조건의 충족/미충족/미확인을 구분했다. 추가 기술스택 묶음을 전체 숙련으로 확대 해석하지 않도록 안내했다.
- SQL 기초 실습을 실무 경력으로 표현하지 않았고, 학력 미충족을 교육 수료로 대체하지 않았다.
- 실제 경험과 성과를 만들어 쓰지 않도록 설명하고, 이력서 예시와 실제 이력을 구분했다.
- 개선 대상: “우대 조건이므로 없다고 탈락하지 않는다”는 문구는 채용 결정을 단정할 수 있다. “우대 미충족만으로 합격·탈락을 판단할 수 없다”로 유도하는 후속 QA가 필요하다.
- 학습 도구 설명은 모델 일반 지식이다. 최신 요금·기능을 별도로 검증한 추천이 아니며 신규 교육 검색도 수행하지 않았다.
- 합성 사례 2건의 기능 성공이며 모든 상담·의도 분류·사실 정확도를 보장하는 평가는 아니다. 일반 대화의 기존 JSON 분기와 출력 길이 안전 제한은 유지한다.

상세 QA 응답·세션 식별자·내부 검증 보고서는 Git 제외 infra/.build에 보관한다. 토큰·비밀번호는 문서에 기록하지 않는다. 이번 요청에서는 커밋·푸시를 수행하지 않았다.
