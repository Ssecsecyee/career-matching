# 검색 후속 탐색·교육 문맥 개선 계획

기준일: 2026-11-02. 아래는 개선 계획이며 배포 완료를 뜻하지 않는다.

## 우선 구현: 다른 공고 추천

“다른 거 추천해줘”, “이거 말고 더 보여줘”는 기존 승인 검색의 다음 결과 요청으로 처리한다. 검색 조건을 다시 생성하거나 모델을 호출하지 않고, 같은 조건에서 이미 노출한 공고 ID를 제외해 조회한다. 최초 목록과 확인 후 목록만 노출 이력에 반영한다. 검색 조건이 바뀌면 이력을 새로 시작한다. 목록 소진 시 조건을 몰래 완화하지 않고 다음 결과 없음을 안내한다. 교육 요청과 조건 변경 요청을 이 경로가 가로채지 않도록 제한한다. 선택한 공고·기존 자기평가를 삭제하지 않는다.

운영 ES의 MySQL 최신 버전/마감 검증과 장애 시 MySQL 복귀에도 제외 ID를 전달한다. 결과 개수는 남은 후보 수라는 의미를 명시한다. 현재 ES 전체 매치 검증 1,000건 상한은 유지하며 무제한 탐색으로 표현하지 않는다.

검증: 연속 페이지 중복 0건, 모델 추가 호출 0회, 검색 확인 재요청 없음, 소진 반복 시 재노출 없음, 새 조건에서는 이력 초기화, ES 장애 시 제외 조건 유지, 교육 의도/상담·명시 조건 변경 미가로채기.

## 이후 개선

1. 백엔드·DevOps 등 직무별 개수 요청의 그룹별 검색·근거 설명.
2. 교육 주제·온라인 선호를 후속 요청에 유지. 조건 검색 0건/모집 미확인/전체 자료 부족 구분. need_topic 빈 안내 반복 제거.
3. [Localization 및 Mapping 역량] 같은 섹션 제목은 분류로 보존하고 독립 평가·집계에서 제외. 원문 손실 없이 검증.
4. 상담은 “보유한 역량” 대신 “충족한다고 답한 경험”으로 근거 수준을 표시. 우대조건 미충족으로 합격·탈락을 단정하지 않기.

원문·수집 데이터·QA 세션·인증 값은 Git에 포함하지 않는다.

## 로컬 구현 결과

다음 공고 의도 판별, 저장된 검색 계획·노출 ID 재사용, ES/MySQL/JSON 저장소의 제한 적용 전 제외, ES 장애 복귀 시 제외 전달을 구현했다. 검색 확인 전에는 노출로 기록하지 않고, 확인 후에 기록한다. 선택 공고·자기평가는 보존한다. 새 검색은 노출 이력을 초기화한다. 기존 확인 완료 세션은 마지막 표시 목록을 기준으로 이력을 시작하며 그 이전의 전체 노출은 복원하지 않는다.

후속 결과의 total은 전체 최초 검색 수가 아니라 앞서 노출한 공고를 제외한 현재 후보 수다. 재확인 과정 없이 다음 목록을 제공한다. 교육 문맥 및 명시적인 조건 변경은 자동 다음 페이지로 처리하지 않는다. 자유로운 모든 표현을 모델로 재분류하는 기능은 아니며 명확한 다음 결과 표현을 지원한다.
