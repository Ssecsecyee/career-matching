# 문답 기반 유사 공고 검색

상태: AWS 배포 완료 · 릴리스 20261103T024842Z

## 목적
사용자가 충족했다고 답한 경험으로 유사한 공고를 탐색한다. 선택 공고의 필수조건은 다음 공고에도 모두 있어야 하는 검색 제한이 아니다. 자기보고를 검증된 실무 역량이나 합격 가능성으로 표현하지 않는다.

## 현재 구현
- 문맥 분류 v4의 search_basis로 직접 검색과 문답 기반 추천을 구분한다.
- 선택 공고의 조건 ID와 연결되는 문답만 제한된 길이로 전달한다. 미확인·미충족을 구분하며 보충 설명은 이 구조에 복사하지 않는다.
- 새로운 필수 기술 필터는 현재 사용자 발화의 인용 근거를 요구한다. 기존 검색에서 유지된 필수 기술은 보존한다.
- 문답에서 추론한 필수 기술은 선호 순위로 이동하고 이유를 검색 기준에 표시한다. 직접 검색에서 필수 필터의 근거가 없으면 확인 질문으로 돌아간다.
- 문답 기반 검색은 선택한 공고를 제외한다. 제안 계획·실행 계획·검증 결과·사용한 자기보고 근거를 기존 search_context와 대화의 _search_record에 기록한다. 새 DB 테이블은 필요 없다.
- 검색 결과가 없다는 이유만으로 조건 완화나 MySQL 우회를 실행하지 않는다.

## 한계와 다음 검증
현재 선호 기술은 기존 태그 검색의 순위 참고다. 도메인·조직 리더십·경험 기간까지 의미 유사도로 비교하는 기능을 새로 구현한 것은 아니다. 직무 조건은 여전히 검색 필터이며, 원 공고 직무명을 그대로 좁게 복사하지 않는지는 실제 모델 평가가 필요하다. 인용 일치 검증은 근거 존재를 확인하지만 문장의 반드시 포함 의미를 완전히 증명하지는 않는다.

실제 모델로 제보 문장을 재현하고, 추천 후보별 유사 경험과 미확인 조건을 설명하는 품질 평가를 추가한다. 유료 모델 호출과 AWS 배포는 이번 로컬 검증에 포함하지 않았다.
