# 대화 흐름 직접 QA 시나리오

배포일 2026-11-02. https://d1elpjlek4sj83.cloudfront.net 을 새로고침하고 새 대화에서 시작한다. 자연어 검색·상담은 실제 모델 사용량이 기록된다. 공고 수와 순서는 데이터에 따라 달라진다. 체크 답변은 본인 경험에 따라 선택한다.

## 1. 검색과 다음 목록

입력: Python과 Docker를 사용해봤어. 관련 백엔드 공고를 찾아줘.

검색 기준이 표시되면 확인한다. 목록 후 입력: 다른 거 추천해줘.

기대: 기존 목록과 중복되지 않는 다음 결과, 추가 검색 기준 확인 없음. 소진 시 조건을 몰래 완화하지 않고 안내한다.

## 2. 필수조건 이후 선택과 대상 표시

공고를 선택하고 필수조건에 응답한다. 일부는 모름으로 선택해 본다.

기대: 필수 완료 후 우대조건 확인 / 현재 답변으로 상담 / 다른 공고 보기 선택이 표시된다. 현재 상담 공고와 버전이 표시되고 모름은 미충족으로 바뀌지 않는다.

현재 답변으로 상담 버튼을 누르거나 입력: 현재 답변으로 보완 방향을 정리해줘.

기대: 필수 답변에 근거한 상담. 미답변 우대조건을 미충족으로 단정하지 않는다.

입력: 다른 공고 추천해줘.

기대: 다음 목록을 보여주되 새 공고 선택 전까지 상담 대상은 이전 공고로 표시된다. 새 공고를 선택하면 표시 대상이 변경된다.

## 3. 우대조건 재개

새 대화에서 공고 선택·필수 답변을 완료하고 우대조건 확인 버튼을 누른다.

기대: 우대조건부터 이어지고 기존 필수 답변을 다시 묻지 않는다. 완료 후 필수/우대의 충족·미충족·미확인·미답변을 구분한다.

## 4. 교육 주제·수강 방식 유지

새 대화 입력: ROS 2 스레드 관리와 성능 최적화를 배울 온라인 부트캠프를 찾아줘.

이어서 입력: 다른 거 추천해줘.

기대: 채용공고로 전환하지 않고 ROS 2 교육 문맥 유지. 조건에 맞는 저장 자료가 없으면 그 범위의 검색 결과가 없다고 설명하며 전체 시장에 교육이 없다고 단정하지 않는다. 교육 다음 결과의 중복 제외 기능은 아직 미구현이다.

이어서 입력: 오프라인으로 바꿔줘.

기대: 주제는 유지하고 수강 방식만 바꿔 조회한다. 방식 미확인 과정을 오프라인으로 간주하지 않는다.

이어서 입력: 이번에는 Python 백엔드 채용공고를 찾아줘.

기대: 명시 요청에 따라 채용 검색으로 전환한다.

## 5. 원문·자기평가 근거

문답 후 입력: 지금 조언의 근거가 뭐야? 내가 직접 말한 내용과 체크한 자기평가를 구분해서 설명해줘.

기대: 현재 선택 공고의 저장 버전과 사용자 답변을 근거로 설명. 경험·경력·성과를 만들어내지 않고 자기평가를 실무 검증으로 표현하지 않는다. 실제 모델 표현은 QA 대상이며 전수 보장하지 않는다.

이상 발생 시 시나리오 번호, 입력, 응답, 현재 상담 공고 이름, 발생 시간을 기록한다. 접속 코드와 토큰은 공유하지 않는다.
