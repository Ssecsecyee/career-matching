## 이용 순서

관리자 페이지 새로고침 → 관리자 토큰 로그인 → ‘문맥·의도 기록’ → ‘조회 / 새로고침’. 필요하면 세션/요청/상태를 지정하고 행의 ‘상세 보기’를 누른다. 분류 출력은 필요할 때만 ‘마스킹된 분류 출력 보기’로 확인한다. 목록과 상세는 만료되지 않은 기록만 표시한다.

분류 오류는 당시 문맥·검증 판단·형식 오류와 모델 호출을 비교하고, 실행 오류는 검증된 행동과 실제 실행 결과를 비교한다. 잘림 표시가 있으면 전체 원본으로 해석하지 않는다. 기본 마스킹이 모든 개인정보 제거를 보장하지는 않는다.
