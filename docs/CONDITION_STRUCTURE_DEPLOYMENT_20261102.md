## 사용 시 주의와 남은 범위

새 분리 규칙을 확인하려면 **새 대화에서 공고를 다시 선택**한다. 이미 열려 있던 구형 세션의 원문/질문을 도중에 다시 나누거나 기존 답변을 새 항목에 옮기지 않는다. 기존 세션 유지·구형 질문 차단은 로컬 회귀 검사에서 확인했고 실제 기존 사용자 세션을 변경해 시험하지 않았다.

문자 위치 검증은 의미적 분리 품질 전체를 보장하지 않는다. 사람의 대화 QA는 계속 필요하다. 수집·정제 단계 공통 조건 세트 저장, 모든 직군의 의미적 분리, 이력서 후속 응답의 출력 한도 문제와 학습 루트 고도화는 이번 배포에 포함하지 않았다.
