# 제품 요구사항

## 2026-10-30 추가 사용자 요구

사용자가 말한 희망 직무와 보유 경험을 유지하고, 보유 기술을 모두 필수로 바꾸지 않는다. 추천 이유 질문에는 해당 세션의 발언과 실제 공고 원문·검색 일치 근거를 연결해 설명한다. 질문 거절은 계속 존중하고 미확인 경력·학력을 충족으로 추정하지 않는다.

상세 계약·실제 재현·저장 책임·추가 작업 순서는 [검색 문맥·추천 근거 개선 계획](SEARCH_CONTEXT_EVIDENCE_PLAN.md)을 따른다. 이 추가 절은 후속 설계이며 이번 문서 수정으로 코드·스키마·운영 기능을 변경하지 않았다.


## 2026-10-29 Elasticsearch 도입 합의와 구현 상태

이 절은 아래 과거 초안의 검색엔진 관련 설명보다 우선한다. **로컬 Nori·동의어 실행과 실제 스냅샷 783건 색인·검색 어댑터 검증을 완료했으며 운영 Elasticsearch는 미도입이다.** 직접 설치 방식으로 진행하며 OpenSearch·Elastic Cloud로 자동 대체하지 않는다. 로컬 Docker에서 분석기·색인·백엔드·동기화를 검증한 뒤 AWS에 배포한다. S3는 원본·백업 저장소이며 검색엔진 설치 위치가 아니다.

목표는 기술명 변형과 복합 직무 표현으로 누락되는 공고를 줄이고 관련성 순위를 개선하는 것이다. 결과 건수 증가만으로 품질 향상을 주장하지 않는다. 초기 범위는 한국어 Nori·기술명 보존·명시적 동의어·기존 필터·키워드 검색이다. 임베딩 검색은 이번 필수 범위가 아니다. 최소 현재 규모의 3배 데이터도 부하 검증 대상으로 잡되 상한으로 보지 않는다.

## 2026-10-28 최신 상태와 고용24 전환 계획

이 절의 실행 현황과 전환 방향을 아래의 과거 초안보다 우선한다. 현재 AWS 웹·대화 서버·EC2 MySQL 연결을 검증했으며 RDS와 Elasticsearch는 사용하지 않는다. 점핏 추가 표본 10건은 백업 후 운영 반영해 총 793건이며, 기존 783건의 버전·해시는 유지했다. 신규 10건의 모집 상태는 unknown이다. **고용24 승인 후 소량 표본 검증을 거쳐 AWS 정기 배치 자동화로 전환**한다. 상세 단계와 통과 기준은 [고용24 파이프라인 계획](../app/ingestion/GOYONG24_PIPELINE.md)을 따른다.

### 고용24 단계별 범위

승인된 채용정보 API에서 최대 10건 표본을 추출해 원문·코드·날짜·상태·누락을 검증한다. 공통 모델 매핑과 격리 적재를 통과하면 Lambda 수집 → 비공개 S3 → 적재 전용 SQS → EC2 MySQL 반영의 수동 1회를 확인하고, 이후 예약 실행·실패 복구를 연결한다. API 정기 조회는 비실시간 배치이며 즉시 웹 동기화를 보장하지 않는다. 교육/훈련 API와 학습 매칭은 별도 후속 범위다.

수정일: 2026-10-28. 대상은 IT 직무 취업 준비생이다.

## 서비스 범위

점핏의 채용 상세정보와 교육 모집정보를 근거로 사용자의 조건을 확인하고 지원 가능한 공고와 학습 방향을 안내한다. 모델 학습·파인튜닝은 초기 범위에서 제외한다.

## 사용자 여정

1. 목표 직무, 기술, 경력, 학력, 지역 등 초기 답변을 받는다.
2. Bedrock이 허용된 검색 계획을 만들고 서버가 후보를 조회한다.
3. 후보 공고가 3개 이상이고 상세 입력 예산 초과가 예상되면 요약 카드를 제시해 공고 선택을 요청한다. 적은 후보라도 길이가 과도하면 선택을 요청한다.
4. 선택한 공고의 자격요건 중 미확인 항목을 먼저 질문한다.
5. 필수 조건 충족을 확인하면 우대사항을 질문한다. 미충족이면 부족 조건과 대안을 안내한다. 불명확하면 추가 확인한다.
6. 확인된 부족 역량에 맞는 교육을 검색하고 원문 근거와 함께 제공한다.

## 데이터 범위

점핏: 제목, 회사, 기술스택, 직무, 날짜, 상세주소, 주요업무, 자격요건, 우대사항, 복지·혜택, 채용절차, 지원 유의사항 및 기타 상세 섹션.

교육: 부트텐트 소프트웨어·AI개발 분야를 희망 출처로 삼는다. 사이트에 무단 크롤링 금지 안내가 있으므로 허락·데이터 제공 협의 또는 허용된 교육기관 출처를 확보한 뒤 수집한다. 정확한 분류 코드와 필드는 실제 검증 전 확정하지 않는다.

## 단계

- 1차: 기존 원본 점검, 상세 보강, 교육 샘플, 공통 데이터 구조, DB 기반 대화 흐름.
- 2차: AWS 저장·예약 수집·React 배포.
- 3차: Elasticsearch 검색 및 변경분 동기화.

## 응답 기준

공고 사실, 사용자 진술, 확인 결과, 학습 제안을 구분한다. 미확인은 미충족이 아니다. 필수 조건에는 학력·경력·자격증 등 비기술 조건도 포함한다. OR/AND 관계와 공고별 차이를 보존한다. 합격 또는 교육 선발을 보장하지 않는다.

## 미정

AWS DB 제품, 모델·리전, 수집 권한, 수집 주기, 비용 상한, 인증·보존 정책은 ../DECISIONS.md에서 결정한다.

## 대화·근거·캐시 저장 보완 (2026-10-28)

추천 이유는 원문 조건·버전·사용자 진술·충족 판정을 연결해 조회할 수 있어야 한다. 숨겨진 추론 기록은 저장하지 않는다. 개인화 캐시는 사용자·세션별로 분리하며 로컬 파일을 운영 기록의 기준으로 사용하지 않는다.


## 교육·학습 루트 데이터 준비 (2026-10-28)
최종 교육 출처는 고용24 국민내일배움카드 훈련과정·일정 API다. 부트텐트는 허락이 없어 실제 스크래핑을 보류하고 직접 작성 가상 표본으로 공통 구조를 준비했다. [교육 데이터 계약·진행 순서](../app/ingestion/TRAINING_DATA_CONTRACT.md)를 따른다. 교육 과정 실수집·운영 적재·매칭 완료를 뜻하지 않는다.

후속 운영 요구사항: 장애를 운영자에게 통지하고, 개인별 관리자 인증/권한 회수·복원 가능한 백업·보존 삭제·사용량 예산·재현 가능한 배포를 갖춘다. 상세 범위·선행 결정·S00~S09 완료 증거는 [보안·운영 개선 계획](SECURITY_OPERATIONS_ROADMAP.md)을 따른다. 기능 출시/보안 인증 완료를 뜻하지 않는다.
