## 검색 정책과 실제 확인

검색 결과 총수가 많아도 중단하지 않는다. 상위 후보를 100건씩, 최대 1,000건 범위에서 MySQL 최신 버전과 검증하고 화면에는 최대 3건을 반환한다. 이미 보여준 교육 제외를 통해 다음 결과를 조회한다. 최대 범위까지 검증한 경우 내부 조회 객체에 search_limited 상태를 기록하며 총수 자체로 오류를 내지 않는다.

시작일 당일 한국시간 00시 이후는 일반 교육 후보에서 제외한다. 시작일 미확인은 신청 후보에서 제외한다. 과거 자료의 참고 조회는 별도 유지한다. 개강 전이라는 이유만으로 신청 가능으로 확정하지 않는다.
