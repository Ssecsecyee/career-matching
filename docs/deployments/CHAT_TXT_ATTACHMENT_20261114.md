# 채팅창 TXT 첨부 UX (2026-11-14)

상태: 구현·검증 후 기존 CloudFront 화면에 반영.

사용 흐름은 채팅 입력창 + → TXT 선택 → 파일명 칩 확인 → 전송 → 오른쪽 유사 공고 목록이다. 별도 공고 업로드 영역은 제거했다. 채팅 문구가 있으면 첨부 내용 뒤에 추가 조건으로 결합한다. 파일명은 브라우저에만 표시하고 서버에는 텍스트만 보낸다. 오류 때 첨부를 유지하고, 정상 반환 때 첨부와 입력을 비운다. 제거 버튼과 새 대화로 첨부를 취소할 수 있다. UTF-8·20KB·2,048토큰 제한 및 임시 처리 보관 정책은 기존과 같다. backend와 모델·ES 색인은 변경하지 않았다.

신규 검증: 파일 형식·인코딩·크기·빈 내용, 전체 문구 보존, 조건 결합과 파일명 미전송의 3개 테스트. 실제 React 화면에서 + 버튼·파일명 칩·파일 단독 전송·vector_search 요청·정상 반환 후 첨부 제거·별도 패널 제거를 확인하는 UI 테스트 1개. 기존 화면 테스트 72개도 통과했다. 프론트엔드 빌드 성공. 이번 테스트는 가상 데이터와 모의 API이며 검색 품질 평가를 추가로 수행한 것은 아니다.
