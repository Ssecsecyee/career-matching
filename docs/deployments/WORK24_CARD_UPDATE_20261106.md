신규 수와 전체 대조 수는 다르다. 같은 과정의 여러 회차를 각각 식별하며 제목만으로 중복 제거하지 않는다.

교육 시작일 2026-11-06~2027-02-04 범위를 공식 API로 재조회했다. 제공자 목록 변동으로 5건 차이가 났던 11월 27일~12월 3일 구간은 하루 단위로 재수집해 건수 차이와 중복 경고 없이 재대조했다. 시점이 고정된 전체 제공자 스냅샷을 보장하는 것은 아니다.

API 원본과 기존 카탈로그를 보존하고 최신 운영 inventory와 해시를 비교했다. 목록 기반 자료는 그대로 목록 검증 수준으로 보관하며 누락 커리큘럼·비용·모집 상태를 추정하지 않았다. 현재 신청 가능 여부는 원문과 기관 확인이 필요하다.

반영 전 전체 DB gzip 백업의 압축 무결성을 확인했다. 변경 전 행도 별도 보관했다. 변경은 기존 해시·버전을 확인하고 버전을 정확히 1 증가시켰으며 Outbox와 같은 트랜잭션에 기록했다. 실제 백업 복원 리허설을 수행했다는 뜻은 아니다.

시작일 도래·미확인 자료 7,486건은 DB 원문을 유지하고 검색 문서에서 제외했다. 다른 훈련 3종은 변경하지 않았다. 전체 DB 전후 inventory 비교에서 신규 6,106건·변경 1,385건·누락 0건을 독립 확인했다.

수집 중 로컬 SQLite 동시 읽기 때문에 중단된 구간은 체크포인트에서 재개했다. WAL과 대기 시간을 적용했으며, 미완료 페이지의 이전 원본도 별도로 보존했다.

코드 검증: ingestion 21개 테스트 통과. 운영 반영 보고서는 비공개 workspace와 기존 배포 산출물에 보관한다. 원본·DB inventory·키는 Git에 올리지 않는다.
