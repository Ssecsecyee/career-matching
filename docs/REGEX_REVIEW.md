## 집계

app/backend/src의 Python AST에서 re 모듈 직접 호출 표현식을 집계한다. 실행 횟수·고유 패턴 수·전체 조건문 수와 다르며 re.escape 같은 보조 호출도 포함한다. 컴파일 객체의 메서드 호출과 문자열 비교는 이 숫자에 포함하지 않는다.

직전 소스 59개 → 현재 소스 32개. 이번에 제거한 27개는 기존 자유 입력 의도 판정이며 같은 기능을 문자열 if로 옮기지 않았다. 이전의 62 → 59 정리는 지역 필터 덮어쓰기와 문구 기반 확인 우회를 제거한 선행 변경이다.
