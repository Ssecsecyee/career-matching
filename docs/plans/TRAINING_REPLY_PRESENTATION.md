# 교육 설명 답변의 목록 재출력 제거

기준일: 2026-11-05
상태: 구현·로컬 검증 완료 / AWS 반영 예정

## 원인

ContextRouter의 training chat 경로가 마지막 교육 목록을 모델 입력으로 전달한 뒤, 같은 목록을 attach(result,learning)로 화면 응답에도 붙였다. 특정 기관·과정 설명이나 비교 뒤 관련 없는 이전 카드 전체가 다시 출력됐다.

## 변경

교육 설명·비교에서는 모델 입력 training_retrieval과 세션 learning_context를 유지하지만, 응답의 learning_opportunities·learning_search는 생성하지 않는다. 따라서 새 카드 목록이 표시되지 않는다. 기존 날짜 상태 갱신과 회차 정보는 계속 보존한다. 교육 목록이 기억에 있으면 training_navigation_available만 반환해 다음 교육 보기 버튼을 제공한다.

새 검색은 기존 기준 확인 절차를 거치며, 확인 후 목록과 다음 결과 요청에서만 카드 데이터를 보낸다. 다음 결과의 shown_ids·shown_groups 제외 규칙과 채용 선택·자기평가 기록은 유지한다. 모델 프롬프트·의도 스키마·문장별 정규식·DB 스키마는 변경하지 않는다. 이전에 저장한 응답 본문과 카드는 소급 삭제하지 않는다.

## 검증

기관 설명·두 과정 비교·추천 상담에서 모델은 이전 목록을 받지만 응답에는 목록 필드가 없는지 확인했다. 선택 채용공고 유지, 새 교육 검색의 재조회, 설명 이후 다음 교육 요청의 기존 표시 ID 제외도 검사했다.

백엔드 전체 487건 중 456 통과·31 건너뜀, 프론트엔드 44건 통과·빌드 통과. 모의 의도·응답을 쓰는 구조 검증이며 실제 모델 의도 분류 정확도 평가는 아니다.
