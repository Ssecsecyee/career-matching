# 신입 검색·집계·복구 문구 수정
상태: 구현 / AWS 배포 완료 (2026-11-07)

신입 단독 검색의 career.levels=[entry]는 실제 필터로 적용한다. 원본 career_source.newcomer=true 또는 제목의 명시적 신입·경력무관, 필수 요건의 명시적 신입 지원 가능을 근거로 한다. 단순 신입 멘토링 언급이나 미확인 경력은 근거가 아니다. 연차 미확인을 신입으로 가정하지 않는다. 원본 확인 전 실무 적합성은 보장하지 않는다.

ES 후보를 MySQL의 최신 원문으로 확인한 뒤 경력 필터를 적용하고 그 결과로 건수와 목록을 함께 만든다. MySQL 대체 경로와 JSON 검증 경로도 동일 정책을 사용한다. 기존 1000건 검증 한도는 유지한다. 주니어/경력 연차 자동 판정은 이번 범위가 아니다.

헤더 전체 후보 건수와 현재 불러온 카드 수를 구분한다. 마지막 조회에서 남은 후보 0건이면 누적된 실제 공고 수로 확정한다. 교육의 회차 수와 과정 카드 수는 다른 단위로 유지한다.

복구 요청을 재시도할 때 기존 '이전 요청/이번에는 한 단계' 래퍼를 한 번만 사용한다. 사용자에게는 간단한 단계 선택 문구를 표시한다. 새 자유 입력은 그대로 기록한다.

운영 검증: 프론트엔드 전체 후보 72건, 명시적 신입 지원 근거를 통과한 후보 0건. 경력/미확인 공고로 결과를 채우지 않음. 이는 저장 데이터의 신입 근거 확인 결과이며 실제 시장의 신입 공고 부재를 의미하지 않음. 프런트엔드 70개·백엔드 528개 테스트 통과(31개 건너뜀).
