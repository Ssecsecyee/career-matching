# 답변 마크다운·상세 링크 표시

기준일: 2026-11-05
상태: 구현·로컬 검증 완료 / 웹 배포 예정

## 원인과 책임

TypingText가 모델 응답을 p 태그의 일반 텍스트로 표시해 ##, **, [이름](주소) 같은 마크다운 기호가 그대로 노출됐다. 에이전트의 검색·도구 선택 문제가 아니라 React 표시 계층의 문제다. AgentCore Harness 전환 계획은 별도 제안·실험이며 이번 작업으로 활성화되지 않는다.

## 수정

react-markdown과 remark-gfm으로 일반 모델 답변의 제목·강조·목록·구분선·표·링크를 렌더링한다. 기존 타이핑과 스트리밍 표시, 전체 보기, 동작 줄이기 설정은 유지한다. 제목 크기·문단 간격·표 가로 스크롤을 답변 영역에 한정해 적용한다.

링크는 짧은 표시 이름과 외부 열기 표시를 사용한다. 명시된 회차 이름은 유지하고, URL 자체가 링크 이름인 경우 고용24 상세 보기 등으로 줄인다. 실제 URL과 회차 쿼리는 유지하며 HTML이나 JavaScript를 실행하지 않는다. HTTPS만 링크로 활성화하고 원시 HTML·외부 이미지·위험 프로토콜은 렌더링하지 않는다. 작성 중인 미완성 마크다운 링크는 긴 주소 대신 링크 작성 중으로 표시한다.

교육 카드·회차의 기존 원문 링크에도 같은 계열의 스타일을 적용한다. 사용자 입력·공고 원문 pre 표시·저장된 모델 답변·DB 근거는 변형하지 않는다. DB 마이그레이션, 모델 프롬프트, 의도 스키마, 검색 로직, 에이전트 실행 방식 변경은 없다.

## 검증

실제 컴포넌트 렌더링으로 제목·강조·목록·구분선·표, 회차 링크의 목적지와 짧은 이름, 긴 자동 링크의 축약, 원시 HTML·이미지·실행 링크 차단, 스트리밍 미완성 링크를 확인했다. 프론트엔드 전체 50건 통과·빌드 통과. npm 설치 시 취약점 보고 0건. 시각적 디자인과 실제 모델 내용 품질은 사용자 QA를 이어간다.
