# 공개 체험 접근
상태: 구현 / AWS 공개 체험 활성화 (2026-11-06)

도메인은 기존 CloudFront 주소 유지. 일반 사용자 접속 코드 입력을 제거한다. AuthSecret.public_access=true일 때만 무인증 요청을 일반 사용자로 허용하며, 잘못된 Authorization 값은 거절한다. 브라우저별 X-Client-Token은 필수로 유지하고 기존 서버 비밀키 기반 소유자 식별을 재사용하여 다른 세션과 비동기 결과를 분리한다.

관리자 API와 관리자 채팅은 기존 관리자 토큰을 요구한다. 일반 사용자 호출 한도, 세션 보관 기간, 입력 검증, API 요청 제한과 DB 대화·근거·모델·의도 기록을 유지한다. 공개 체험 안내에 기록 사실과 개인정보 미입력을 표시한다.

되돌리기: AuthSecret.public_access=false 및 hosting.py publish --no-public-access. 비밀키 자체를 공개하거나 삭제하지 않는다. 새 AWS 자원을 만들지 않는다.

검증: 무인증 검색 200 및 세션 생성, 타 브라우저 결과 조회 404, 무인증 관리자 403, 잘못된 토큰 401. 검증 중 모델 호출 없음. 프런트엔드 69개·백엔드 523개 테스트 통과(31개 건너뜀).
