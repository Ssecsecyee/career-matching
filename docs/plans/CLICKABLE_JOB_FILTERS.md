# 클릭형 채용공고 필터
상태: 구현 / AWS 배포 완료 (2026-11-07)

공고 화면은 검색 컬럼 드롭다운 대신 통합 검색창, 직무·지역·신입 조건·기술 카테고리 버튼을 제공한다. 교육 검색은 키워드 입력만 유지한다.

## DB와 검색 연결
- 통합 검색: title, company_name, responsibilities, qualifications, preferred_requirements, tech_stacks. SearchPlan v2.text_query로 전달.
- 직무: titles/주요업무/자격요건을 검색하는 직무 관련 검색어. 공식 직무 분류코드로 확정한 값이 아니다.
- 지역: addresses/location_text. 여러 지역은 OR.
- 신입: career_source 및 현재 원문에 명시된 신입 가능/경력무관 근거. 미확인 제외.
- 기술: tech_stacks. 표시된 공고의 실제 태그를 선택지로 사용하며 직접 추가도 가능. 여러 필수 기술은 AND.
- 서로 다른 카테고리는 AND. 공개된 신입 조건 이외의 학력·연봉·고용형태를 임의 생성하지 않는다.

## 사용
카테고리를 펼쳐 복수 선택한 뒤 선택 적용. 조건 칩을 클릭하면 하나씩 해제하고 재조회. 통합 검색어와 카테고리는 함께 적용. 전체 초기화는 모든 조건을 비운다. 필터는 전체 검색 데이터에 적용하며 AI를 호출하지 않는다.

서버가 applied_search_plan을 반환하여 AI로 검색한 직무·지역·필수 기술·신입 조건도 같은 입력에 반영한다. 사용자의 보유·선호 기술 순위 조건은 유지한다. 현재 화면에 불러온 태그 선택지가 전체 DB 태그 집합이라는 의미는 아니다.

모바일은 버튼을 줄바꿈하고 선택 패널을 본문에 표시하여 공고를 가리는 팝업을 추가하지 않는다.

검증: 화면 71개·서버 529개 테스트 통과(31개 건너뜀). 배포된 일반 사용자 화면에서 지역 경기 적용 후 243건·20개 카드 표시 및 조건 칩 유지 확인. 검증 검색은 모델 호출 없이 진행.
