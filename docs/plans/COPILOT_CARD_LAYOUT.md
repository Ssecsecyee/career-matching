## 화면 구성

참고 화면의 정보 배치를 적용해 탐색 화면을 좁은 이동 메뉴·왼쪽 AI 검색 도우미·오른쪽 카드 목록으로 나눈다. 탐색 화면의 상단 탭은 공고/교육이며, 독립 AI 상담은 왼쪽 메뉴에서 접근한다. 전체 상담 화면에서는 기존 대화도 유지한다.

기업/기관 로고 대신 기업·기관명을 넣은 컬러 배지를 사용한다. 이름 해시로 제한된 팔레트에서 색상을 결정해 다시 렌더링해도 같은 이름의 색이 바뀌지 않는다. 흰 글씨와 팔레트의 대비를 단위 테스트했다. 외부 로고 다운로드나 실시간 이미지 생성은 하지 않는다.

카드는 기업·기관명, 지역, 제목, 기술 또는 저장된 설명, 원문 링크, 모집 확인 안내 또는 일정 상태를 표시한다. 없는 경력·마감·비용·기업 규모를 만들어 표시하지 않는다. 카드 클릭은 읽기 상세 패널만 연다. 상세에서 지원조건 확인하기 또는 이 교육 설명해줘를 명시적으로 누르면 기존 서버 행동을 호출해 왼쪽 AI에서 이어간다.

왼쪽 대화에서는 같은 카드 전체를 다시 나열하지 않고 대화·기준 확인·다음 결과 버튼을 유지한다. 결과가 채용이면 공고, 교육이면 교육 탭으로 연결하되 독립 상담 화면을 강제로 탐색 화면으로 바꾸지 않는다. 메뉴 이동 시 동일한 대화와 문답 초안은 유지한다.

오른쪽 검색창·지역 필터는 현재 확인된 목록 안에서만 동작하며 추가 API나 모델 호출을 하지 않는다. 건수도 최근 검색 목록의 표시 개수로 한정한다. 전체 DB 탐색 API·전체 목록 페이지네이션·경력/기업규모 필터가 구현된 것으로 표시하지 않는다. 최근 0건 결과에서는 과거 목록을 다시 보여주지 않는다.

모바일에서는 한 열 카드와 AI에게 조건 말하기 버튼을 사용한다. 버튼으로 대화 패널을 열고 닫는다. 큰 화면은 3열, 중간 화면은 2열, 좁은 화면은 1열로 배치한다.

## 검증

프론트엔드 55건 통과·웹 빌드 통과. 모의 서버를 이용하는 실제 React DOM 테스트에서 목록 내 검색·지역 필터·필터 초기화, 추가 검색 요청 없음, 상세의 명시적 지원조건 확인 후 AI 문답 연결, 탭 왕복의 대화·미저장 답변 보존을 확인했다. 배지 색 안정성과 대비도 검증했다.

로컬 브라우저에서 합성 자료 6개로 카드·기업명 배지·좌측 AI 배치를 확인했다. 390px 모바일 화면에서 가로 넘침이 없고 AI 패널이 열리고 닫히는 것을 확인했다. 합성 자료와 모의 API는 infra/.build의 로컬 검증 전용이며 실제 서비스 코드·운영 목록에 넣지 않는다. 실제 Bedrock 호출이나 DB 변경은 시각 검증에서 실행하지 않았다.

## 버전 관리

새 커밋·새 태그·새 미리보기 경로를 사용한다. 이전 미리보기와 기존 운영 루트는 교체하지 않는다. UI 변경이며 AgentCore·DB·검색 스키마·서버 인프라는 변경하지 않는다. 복구 시 직전 단계 미리보기 주소를 사용하거나 이 레이아웃 커밋을 별도 revert한다. 기존 상태 유지 기반과 독립된 범위로 보관한다.
