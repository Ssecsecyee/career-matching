# 상담 팝업

상태: 구현 · 별도 미리보기 배포 완료

공고·교육 탐색 위에 같은 상담 컴포넌트를 팝업으로 표시한다. 상담 화면에서 열면 공고 탐색으로 이동한다. 최소화와 닫기는 창만 숨기며 대화, 입력 초안, 저장 전 조건별 답변은 유지한다. 화면에 고정하면 기존 왼쪽 패널로 돌아간다. Escape로 최소화할 수 있다. 페이지 새로고침까지 초안을 보관하는 기능은 아니다.

관리자 인증 경계와 검색·문답 API는 변경하지 않는다. 팝업을 열거나 닫는 동작은 모델을 호출하지 않는다.

검증: 프론트엔드 55개 테스트 통과. 실제 컴포넌트에서 열기·최소화·닫기·재열기·고정 후 동일한 입력창과 문답 선택 유지, 추가 요청 없음, 관리자 모드 인증 분리를 확인했다.

feature/copilot-workspace 브랜치에서 별도 커밋과 태그로 보관하며 기존 main 및 미리보기 주소는 유지한다.

미리보기: https://d1elpjlek4sj83.cloudfront.net/previews/ux-popup-c9323f8/index.html#jobs

코드 커밋: c9323f8 · 태그: ux-workspace-popup-20261105. 빌드 통과 및 CloudFront HTML 200·전용 자산 경로 확인. 기존 root 서비스와 이전 미리보기는 교체하지 않았다. 미리보기의 대화 요청은 기존 운영 백엔드를 이용한다.
