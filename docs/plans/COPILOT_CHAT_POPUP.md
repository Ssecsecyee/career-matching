# 상담 팝업

상태: 구현 · 별도 미리보기 배포 완료

공고·교육 탐색 위에 같은 상담 컴포넌트를 팝업으로 표시한다. 상담 화면에서 열면 공고 탐색으로 이동한다. 최소화와 닫기는 창만 숨기며 대화, 입력 초안, 저장 전 조건별 답변은 유지한다. 화면에 고정하면 기존 왼쪽 패널로 돌아간다. Escape로 최소화할 수 있다. 페이지 새로고침까지 초안을 보관하는 기능은 아니다.

관리자 인증 경계와 검색·문답 API는 변경하지 않는다. 팝업을 열거나 닫는 동작은 모델을 호출하지 않는다.

검증: 프론트엔드 55개 테스트 통과. 실제 컴포넌트에서 열기·최소화·닫기·재열기·고정 후 동일한 입력창과 문답 선택 유지, 추가 요청 없음, 관리자 모드 인증 분리를 확인했다.

feature/copilot-workspace 브랜치에서 별도 커밋과 태그로 보관하며 기존 main 및 미리보기 주소는 유지한다.

## 상담 페이지 제거 · 팝업 단일화

2026-11-06 일반 사용자 전체 상담 페이지를 제거했다. 기본 주소와 기존 #chat은 #jobs로 정규화한다. 메뉴는 공고·교육만 제공하며 사이드 상담 버튼·상단 버튼·우측 하단 버튼은 같은 팝업을 연다. 초기에는 최소화 상태이고 고정 패널 전환 버튼은 제거한다. 공고 문답·교육 설명 선택은 팝업을 열어 이어간다. 창을 닫아도 동일 컴포넌트의 대화·초안·문답 상태를 유지한다. 관리자 전용 채팅·인증 경계는 유지한다. 프론트엔드 60개 검사 통과.

## 요청 해석 정정

사용자 요청은 팝업 단일화가 아니라 큰 상담 페이지 이동 제거였다. 왼쪽 고정 상담 패널을 기본으로 복원하고 선택적 팝업 전환을 유지한다. 공고 문답·교육 설명·상담 이어가기는 현재 탐색 페이지의 왼쪽 상담창을 열며 해시를 변경하지 않는다. 기존 #chat의 공고 화면 연결은 유지하여 큰 상담 전용 페이지를 사용하지 않는다.
