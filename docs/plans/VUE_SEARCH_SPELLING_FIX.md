# Vue 검색 표기 누락 수정

기준일: 2026-11-05
상태: 구현·AWS 배포·운영 검색 확인 완료

## 운영 원인 확인

동일 시점·보유 기술만 지정한 구조화 검색에서 Vue는 ES 운영 경로와 MySQL 모두 0건, Vue.js와 VueJs는 모두 16건, React는 53건이었다. ES tech_query 분석 결과는 Vue → vue, Vue.js → vue.js로 서로 달랐다. 공통 skill_terms는 vuejs와 vue.js만 묶었고 vue 항목이 없었다. 따라서 저장 공고 부재가 아니라 표기 연결 누락이다. 특정 과거 요청의 DB 의도 로그를 재현한 것은 아니며, 첨부 화면과 동일한 검색 조건으로 현재 검색을 비교한 결과다.

## 변경

structured-search-v3의 공통 검색어 매핑에서 Vue, Vue.js, VueJs를 대소문자 구분 없이 동일한 표기군으로 확장한다. ES 쿼리·MySQL 장애 복귀 검색·로컬 JSON 구조화 검색이 같은 정의를 사용한다. 모델 프롬프트·분류 스키마·공고 원문·ES 분석기·색인은 변경하지 않는다. Vuex, Nuxt.js는 별도 기술로 유지한다.

보유 기술 하나 이상 OR, 필수 기술 간 AND, 선호 기술 순위 반영의 기존 의미는 유지한다. 레거시 v1 계약의 문자 그대로 필터는 이번 변경 범위가 아니다. 사용자에게 보여주는 기술명은 요청 표기를 유지한다.

## 검증

표기군 대칭·대소문자, 별도 기술 제외, 보유/필수/선호의 ES·SQL 쿼리 동일성, 필수 AND·보유 OR 회귀 검증을 추가했다. 전체 백엔드 481건 중 450 통과·31 건너뜀. 모델 호출은 필요하지 않으며 실제 의도 분류 정확도 평가는 별개다.

## 후속

새 검색으로 다시 확인한다. 기존 저장된 0건 응답·검색 확인 화면은 소급 수정하지 않는다. 다음 과업은 같은 교육의 여러 회차를 묶어 표시하는 작업이다.

운영 release 20261105T012447Z 배포 후 Vue·Vue.js·VueJs는 각각 ES 운영 경로 및 MySQL에서 모두 16건, React는 기존 53건으로 확인했다. ES 분석기를 수정하지 않아도 공통 쿼리 확장으로 해결되었다. 검증 중 모델 호출·DB 변경은 없다.
