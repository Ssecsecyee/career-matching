# 모바일 전용 워크스페이스 구성

작성일: 2026-11-17. 로컬 구현·검증 완료, 운영 배포 전.

- 일반 사용자 화면의 너비가 767px 이하일 때만 모바일 구성 적용. 관리자와 PC 화면의 기존 좌우 배치는 유지.
- 기본 상담 화면에 넓은 대화 영역과 하단 입력창 제공. 첫 화면의 안내는 초기 목록 요청이 있어도 유지.
- 하단 상담 / 검색 결과 / 내 페이지 탭. 결과 화면 안에서 공고 / 교육 전환.
- 검색 결과를 받았다고 상담 화면을 자동으로 덮지 않음. 찾은 결과 보기 버튼과 하단 탭으로 이동.
- 공고의 내 역량 확인하기·교육 설명 버튼에서는 상담으로 복귀. 모바일에서는 불필요한 키보드 자동 열기를 피함.
- 탭 이동 시 대화·입력 초안·대화 스크롤·검색창 입력·목록·스크랩 상태 보존. 보이지 않는 패널의 무한 스크롤 조회를 중지.
- visualViewport 높이·위치 변경에 대응하고 안전 영역 여백 적용. 화면 전환만으로 새 AI 호출을 만들지 않음.

## 검증

- 프런트엔드 80개 테스트 통과, 빌드 성공.
- Chromium 실제 빌드 + 합성 API 응답으로 360 / 390 / 430px 모바일 및 1440×1000 PC 확인.
- 하단 탭·입력 DOM/초안 보존·직접 검색 입력 보존·스크랩 조회·공고/교육 전환·역량 문답 진입 확인.
- PC 헤더 72px·상담 폭 340px 및 좌우 패널 동시 노출 유지 확인.
- 키보드는 visualViewport 높이 감소 시뮬레이션으로 입력창이 가려지지 않음을 확인. 실제 iOS Safari·Android 기기의 키보드 및 주소창 동작은 추가 확인 필요.
- 실제 AWS·Bedrock 호출이나 운영 배포는 하지 않음.

코드: app/frontend/src/CareerApp.jsx, MobileWorkspaceNavigation.jsx, mobileWorkspace.test.js, style.css, index.html.
검증 자료: ChatGPT 프로젝트 outputs/mobile_workspace_20261117.
