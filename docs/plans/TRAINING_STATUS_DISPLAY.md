# 교육 일정·모집 상태 분리

기준일: 2026-11-05
상태: 구현·AWS 배포·운영 검색 확인 완료

## 문제

recommendation_eligible=false인 모든 교육에 과거 회차 또는 모집 미확인이라는 문구를 붙여, 시작 전 교육도 과거 자료처럼 보였다. 상담에도 같은 경고 문구가 전달됐다.

## 현재 구현

- 일정은 upcoming(시작 예정), ongoing(진행 중), ended(종료), unknown(일정 미확인)으로 계산한다. 시작만 지났고 종료일이 없으면 진행 중 또는 종료를 추정하지 않는다.
- 모집 표시는 open_recorded(모집 중으로 기록), closed(마감으로 기록), deadline_elapsed(신청 마감일 경과), unknown(모집 여부 미확인)으로 분리한다. 원문의 recruitment_status는 덮어쓰지 않는다.
- 날짜만 있는 종료일은 한국 시간 해당 날짜 말까지 포함한다. 시간 있는 DB 값은 기존 UTC 저장 규칙을 따른다.
- 시작 예정이라는 사실은 모집 중·신청 가능·지원 자격 충족을 의미하지 않는다. 기존 신청 후보 검증 조건은 강화된 상태 계산과 함께 유지한다.
- MySQL/ES 조회 후 카드 생성에서 공통 계산한다. ES도 기준 MySQL의 종료일을 읽는다. DB 스키마·원본·색인은 변경하지 않는다.
- 교육 상담 시 마지막 표시 교육의 일정 상태를 현재 시각으로 다시 계산해 모델에 전달한다. 이는 외부 모집 상태를 새로 조회한 것이 아니다. 모델에는 일정과 모집 상태를 구분하도록 안내한다.
- 기존 저장 응답에 새 필드가 없으면 화면은 일정·모집 미확인으로 표시한다. 이미 기록된 과거 메시지 본문은 소급 변경하지 않는다.

## 검증

미래·모집 미확인 교육, 미래지만 모집 마감인 교육, 한국 시간 종료일 경계, 신청 마감일 경과, 종료일 미확인, 저장 카드 상태 갱신과 원본 보존을 검증했다. 백엔드 전체 478건 중 447 통과·31 건너뜀, 프론트엔드 43건 통과, 웹 빌드 통과. 실제 모델 품질 정확도 평가를 뜻하지 않는다.

## 후속 순서

Vue 검색 누락 원인 확인 → 같은 교육 회차 묶기 → 교육 설명 시 기존 카드 재출력 분리. 해당 후속 기능은 이번 수정에 포함하지 않는다.

AWS SSO 갱신 후 release 20261105T011442Z 및 웹 배포 완료. 운영 React 교육 검색 3건이 모두 upcoming·recruitment unknown·recommendation_eligible false로 반환되고 과거 회차 경고가 없는 것을 확인했다. 검증은 읽기 전용이며 모델 호출 0회·DB 변경 0건이다.
