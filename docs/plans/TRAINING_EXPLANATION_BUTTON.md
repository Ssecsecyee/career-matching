# 교육 설명 버튼

기준일: 2026-11-05
상태: 구현·로컬 검증 완료 / AWS 반영 예정

## 동작

교육 카드마다 이 교육 설명해줘 버튼을 제공한다. 새 요청은 explain_training 행동과 source·source_id·source_version(문자열), session_id·request_id를 보낸다. 클라이언트가 과정 본문·기관명·프롬프트를 주입하지 않는다.

서버는 해당 세션의 마지막 실제 표시 목록 learning_context.courses에서 출처·ID·버전이 일치하는 교육을 찾는다. 없거나 목록이 바뀌었으면 training_reference_changed(409)로 거절한다. 인증·세션 소유자·호출 한도는 기존 정책을 따른다.

유효한 버튼 요청은 의도 분류 모델을 거치지 않고 training chat으로 직접 연결한다. 설명 모델의 training_retrieval에는 선택한 교육 하나와 그 회차들만 전달한다. 요청된 교육의 일정·비용·모집 상태·지원 자격을 저장 근거로 설명하도록 요청하며, 상세 정보가 없으면 추측하지 않는다. 새 웹 상세 수집은 수행하지 않는다.

선택 범위는 해당 설명 한 번에만 적용한다. 전체 교육 목록·탐색 제외 기록·채용 답변은 보존하므로 이후 비교와 다음 교육 탐색을 이어갈 수 있다. 설명 응답에 이전 카드 목록을 붙이지 않는다. 이전 카드·처리 중 버튼은 비활성화한다.

의도 판단 기록에는 direct_action=explain_training과 교육 식별자를 남기고, 설명은 기존 대화·모델 호출 기록을 사용한다. DB 테이블·원문·ES 색인·의도 모델 스키마 변경은 없다. 새로운 UI 행동을 검증하는 서버 분기이며 사용자 문장별 정규식이나 프롬프트 예외 추가는 아니다.

## 검증

버튼의 정확한 식별자 전송, 단일 교육·회차 모델 입력, 다른 목록과 자기평가 보존, 카드 재출력 방지, 의도 분류·재검색 미호출, 오래된 참조·위조 대상 거절, 클라이언트 본문·추가 필드 거절, 직접 행동 감사 기록을 검증했다.

백엔드 전체 491건 중 460 통과·31 건너뜀, 프론트엔드 46건 통과·웹 빌드 통과. 단위 테스트는 모의 모델 응답을 사용하며 실제 모델의 설명 정확도 평가를 뜻하지 않는다.
