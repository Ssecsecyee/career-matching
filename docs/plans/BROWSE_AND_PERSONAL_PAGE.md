# 공고·교육 탐색 및 내 페이지
상태: 구현 · AWS 배포 완료 (2026-11-06)

- 기존 지역·텍스트 검색에 공고 기술 / 교육 수강 방식 필터 추가. 불러온 목록만 필터하며 전체 데이터 필터로 오인하지 않도록 표시한다. 글로벌 필터 API는 후속 과제다.
- 20개 단위 번호 페이지. 이전 페이지는 캐시된 목록에서 재표시하고 다음 미수신 묶음만 기존 next_results로 요청한다. 스크롤 자동 요청은 제거하며 모델을 추가 호출하지 않는다. 새 검색과 필터 변경 시 1페이지로 돌아간다.
- 카드 모집 원문 버튼과 출처 링크 모두 안전한 HTTPS 새 창 링크. 상세 창은 바깥 클릭·Esc·확대한 X로 닫는다.
- 개인정보 저장 범위: 브라우저 localStorage이며 회원 계정 기반 DB가 아니다. 같은 브라우저 프로필에서는 공유되며 기기 동기화·계정별 접근 제어는 제공하지 않는다. 로컬 전체 삭제 제공. 저장 실패는 안내한다.
- 스크랩·최근 항목의 원문 및 모집 상태는 저장 당시 스냅샷일 수 있다. 원문 링크로 재확인한다.
- 후속: 회원 인증 도입 후 소유자별 서버 저장과 기기 동기화, 전체 검색 대상의 서버 필터 및 임의 페이지 이동 API.
- 상담용 이력서 UI·파일 가져오기·상담 전달 기능은 사용자 요청으로 제거했다. 기존 로컬 이력서 필드는 읽지 않으며 이후 개인 기록 저장 시 보관하지 않는다. 최근 본 항목과 스크랩은 유지한다.
