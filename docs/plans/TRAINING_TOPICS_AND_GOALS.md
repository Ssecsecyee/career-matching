# 교육 전문 분야와 학습 목표 분리

기준일: 2026-11-05
상태: 구현·로컬 검증 완료 / AWS 반영·실제 모델 소량 확인 예정

## 재현

데이터분석 교육과 포트폴리오 제작을 요청했으나 topics에 데이터분석과 포트폴리오가 함께 들어갔다. 기존 교육 주제 검색은 OR이므로 광고·출판·편집디자인 포트폴리오 교육도 후보가 됐다. 반면 해당 알파코 설명의 저장 응답 JSON에서 message를 추출한 결과 정상 제목 7개·이름 있는 HTTPS 링크 3개이며 이스케이프된 제목·별표나 중첩 링크는 없었다. 제공된 복사 텍스트만 보고 원문 역슬래시 제거를 추가하지 않는다.

## 변경 계약

context-intent-v6에서 교육 search/refine_search에 learning_goals(최대 8개·각 60자)를 추가했다. topics는 실제 전문 분야·기술·기관, learning_goals는 결과·활용 목표다. 의미 구분은 Sonnet의 프롬프트·스키마로 수행하고 단어별 정규식 제거·차단 목록은 추가하지 않는다.

예: 데이터분석을 배우고 포트폴리오를 만들려는 요청은 데이터분석을 검색하고, 데이터분석 포트폴리오 제작을 희망 목표로 기록한다. 디자인 포트폴리오 자체가 실제 교육 주제인 요청은 디자인 분야를 보존한다. topics의 기존 OR을 모두 AND로 바꾸지 않는다.

learning_goals는 검색 기준·확인 후 탐색 문맥·상담 문맥에 보존하되 ES/MySQL 검색어로 전달하지 않는다. 학습 목표 지원 여부는 현재 목록 중심 자료로 검증하지 못하므로, 검색 기준 limitations에 희망 목표와 미확인 사실을 표시한다. 포트폴리오 지원 과정으로 확정 추천하거나 새로운 커리큘럼을 만들지 않는다.

기존 요청은 새 필드 생략 시 그대로 동작한다. refine_search에서 생략은 기존 목표 유지, 빈 배열은 목표 해제다. 새 search는 이전 목표를 자동 누적하지 않는다. DB 테이블·검색 인덱스·직접 버튼 계약 변경은 없다.

## 검증

추가 단위 검증은 모델 결정 예시를 주입해 분야만 검색에 전달되고 목표는 저장·확인·표시 문맥에 유지되는지 확인한다. 전체 백엔드 492건 중 461 통과·31 건너뜀. 실제 모델 분류는 별도의 소량 smoke로 확인하며 정식 정확도 지표와 구분한다.
