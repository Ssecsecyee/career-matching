# 컬럼별 직접 검색
상태: 구현 / AWS 배포 완료 (2026-11-06)

검색 버튼과 Enter는 조건을 서버에 직접 전달하며 AI·문맥 분류를 호출하지 않는다. 입력 도중에는 결과를 바꾸지 않고 제출한 조건으로 전체 저장 데이터를 조회한다.

공고 컬럼: 전체 내용·제목·회사명·주요업무·자격요건·우대사항·기술. 지역과 쉼표 구분 필수 기술(AND)을 추가한다. 기존 SearchPlan과 ES/MySQL 검색 어댑터를 사용하고 텍스트 컬럼은 허용 목록으로 검증한다.

교육 컬럼: 전체 내용·과정명·교육기관·교육내용·학습 주제·NCS 코드. 지역·수강 방식·훈련 종류를 함께 적용한다. 주소와 NCS 등 현재 색인에 없는 컬럼을 포함하므로 직접 교육 검색은 MySQL의 파라미터화된 SELECT/COUNT를 사용한다. AI 교육 검색은 기존 ES 경로를 유지한다.

같은 조건은 무한 스크롤의 다음 조회에도 유지한다. 총 교육 건수는 회차 기준이며 목록은 기존 과정·기관 묶음을 재사용한다. 시작일 도래·마감 제외 정책과 기존 1000건 조회/세션 탐색 상한을 유지한다. 제공되지 않은 비용·지원 대상·커리큘럼은 추정하지 않는다.

검색어는 SQL 값으로만 바인딩하며 사용자 입력을 임의 컬럼명·정렬식으로 연결하지 않는다. 초기화는 입력과 서버 검색을 함께 초기화한다. 수동 검색 0건일 때 이전 결과를 재사용하지 않는다.
