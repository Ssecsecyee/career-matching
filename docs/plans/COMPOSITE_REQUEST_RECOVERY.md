# 복합 요청의 단계별 복구 안내

상태: 구현
기준일: 2026-11-06

“데이터분석가가 되고 싶은데 내 역량을 평가해서 교육까지 추천해줘”는 유효한 복합 요청이다. 모델 응답 형식 오류를 사용자 문장 오류나 문맥 이해 실패로 단정하지 않는다. 정상 처리 가능한 복합 요청은 기존 흐름을 유지한다.

ModelOutputFormatError일 때만 서버는 실패 상태와 오류 코드를 유지하며 단계 선택이 필요하다는 안내를 반환한다. 프론트는 새 대화로 초기화하는 버튼 대신 “역량 확인부터”, “교육 찾기부터”를 제시한다. 사용자가 고르면 원래 요청을 포함한 한 단계 요청을 같은 세션에 보낸다. 자동 유료 재시도는 하지 않는다. 기존 답변과 기록은 유지한다. 출력 잘림·서비스 장애·인증 오류는 이 단계 선택과 구분한다.

이는 응답 형식 오류 자체를 모두 제거한 것이 아니라 대화가 끊기는 상황의 복구 UX다. 현재 에이전트 사용량·권한·실험 횟수 제한은 변경하지 않는다.
