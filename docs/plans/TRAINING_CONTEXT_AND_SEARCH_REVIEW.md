# 교육 탐색 문맥과 검색 기준 확인

상태: 구현·AWS 배포 완료 / 실제 모델 소량 검증 9개 점검 통과
기준일: 2026-11-04

## 해결할 문제

교육공고를 명시적으로 요청해야만 저장 교육 검색으로 넘어가고, 배우고 싶다는 표현이나 기관 탐색은 일반 상담에 머무는 문제가 있었다. 채용과 달리 교육 검색은 기준 확인 없이 목록을 바로 표시했다.

## 현재 동작

1. Sonnet 문맥 분류가 최근 대화와 현재 대상을 보고 실제 교육기관·과정 탐색인지 판단한다. “React 배우고 싶어”, “어디서 배울 수 있어?”, 기관명 기반 과정 탐색도 포함한다. 교육 대상이 없으면 한 가지 확인 질문을 한다.
2. 개념 설명, 독학 방법 설명, 과거 수강 경험만 말하는 경우는 일반 대화로 유지한다. 새로운 정규식·키워드 라우팅을 추가하지 않았다.
3. 교육 검색은 저장 자료를 조회한 뒤 주제·기관 검색어, 시작 전 자료 조건, 수강 방식과 후보 수를 먼저 보여준다. 후보 수는 검색엔진 집계이며 신청 가능한 교육 수를 뜻하지 않는다. 전체 집계가 없으면 확인한 표본 수만 표시한다.
4. 사용자가 확인 버튼 또는 자연어로 동의하면 같은 조건을 다시 조회한다. 공고 ID·버전·내용 해시가 바뀌면 새 기준 확인을 요구하며, 일치하면 교육 3건을 표시한다.
5. 확인 전 다음 목록 요청은 동의를 우회하지 않는다. 확인 후에는 이미 표시한 교육을 제외하고 다음 결과를 조회한다. 기존 선택 채용공고·조건 답변과 마지막으로 실제 표시한 교육은 유지한다.

## 구조와 기록

- 문맥 계약: context-intent-v5. 기존 confirm_search 행동을 jobs/training 대상으로 공유한다.
- 교육 단계: training_search_review → 확인 → conversation. 결과 없음은 training_no_results.
- 세션 JSON에 training_search_context와 검색 ID·기준·후보 버전을 저장한다. 응답 저장 시 _training_search_record로 해당 시점 기준을 보관한다. 테이블 변경은 없다.
- 문맥 입력에는 교육 기준 확인 대기 상태를 포함한다. 버튼은 모델 분류 없이 처리하고 자연어는 모델이 행동을 선택한다.
- React SearchReview를 채용·교육이 공유하고 교육 확인 중 빈 학습 추천 상자는 숨긴다.
- 실제 교육 데이터는 MySQL 기준, Elasticsearch 검색 사본을 사용한다. 시작 전이라는 조건은 모집 중·신청 가능·지원 자격 충족의 증명이 아니다.

## 수정 파일

- app/backend/src/bedrock/prompts.py, client.py: 교육 탐색과 개념 상담 구분.
- app/backend/src/schemas/intent.py, services/intent_context.py: 계약 버전·대상·대기 문맥.
- app/backend/src/services/context_router.py, training_review.py, dialogue.py: 미리보기·동의·버전 재확인·다음 목록.
- app/backend/src/repositories/mysql_chat.py: 검색 기준 기록. elasticsearch_training.py와 search_failover.py: 후보 집계 전달.
- app/frontend/src/SearchReview.jsx, main.jsx: 교육 확인 화면과 오류 안내.

AWS 작업자 release 20261104T115457Z 및 웹 배포 완료. 실제 Sonnet 소량 검증 9개 점검을 통과했다. 배우고 싶다는 요청, 배울 곳·기관 탐색, 대상 확인 후 짧은 후속 답변, 채용에서 교육 전환, 개념 설명과 과거 경험 분리, 확인 버튼을 검사했다. 확인 버튼은 추가 모델 호출 0회로 재조회 후 3건을 표시했다. 데이터 분석 학원 요청은 교육 검색으로 분류됐지만 저장 검색 결과가 없었으므로 검색 품질 개선은 별개로 남는다. 검증용 합성 세션·호출은 기존 DB 기록에 포함된다. 모의 모델 단위 테스트나 소량 smoke를 정식 의도 정확도 평가로 해석하지 않는다. 고정 평가셋, 교육 상세 보완, 일일 자동 수집은 후속 작업이다.
