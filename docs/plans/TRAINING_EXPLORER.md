# 교육 탐색 화면

상태: 구현

공고와 동일한 상담 패널·3열 카드·오른쪽 상세창을 사용한다. 교육 탭 첫 진입 시 browse_training 직접 요청으로 모델 호출 없이 시작일 이전 전체 교육 중 최대 20개 과정 그룹을 조회한다. 회차는 그룹 내 최대 5개이며 후보 건수는 회차 수일 수 있어 과정 수로 단정하지 않는다.

탐색 중 자연어 검색은 기존 AND/OR·수강 방식·시작일 필터를 사용하고 서버 검색 기준 확인 후 목록에 적용한다. 스크롤로 다음 그룹을 중복 없이 누적한다. 전체 교육 초기화, 수동 다음 버튼을 제공한다. 숨겨진 탭과 처리·재시도 대기 중에는 자동 조회하지 않는다.

상세창은 저장된 교육 내용·지원 대상·비용 설명·회차별 일정·원문을 표시한다. 상세 API 자료가 없는 값은 생성하지 않으며 모집 미확인 표시는 유지한다. 이전 페이지의 교육 설명 버튼도 노출 이력에 있는 과정과 버전을 참조한다. 공고 선택과 역량 답변은 교육 초기 조회로 지우지 않는다.

제한: 기존 저장소의 조회 범위·세션당 1000개 탐색 제한은 유지한다. 후보 소진은 추가 조회 한 번으로 확인할 수 있다. 원문 최신 여부·지원 자격·신청 가능 여부는 기관 확인이 필요하다.
