# 교육 탐색 화면

상태: 구현

공고와 동일한 상담 패널·3열 카드·오른쪽 상세창을 사용한다. 교육 탭 첫 진입 시 browse_training 직접 요청으로 모델 호출 없이 시작일 이전 전체 교육 중 최대 20개 과정 그룹을 조회한다. 회차는 그룹 내 최대 5개이며 후보 건수는 회차 수일 수 있어 과정 수로 단정하지 않는다.

탐색 중 자연어 검색은 기존 AND/OR·수강 방식·시작일 필터를 사용하고 서버 검색 기준 확인 후 목록에 적용한다. 스크롤로 다음 그룹을 중복 없이 누적한다. 전체 교육 초기화, 수동 다음 버튼을 제공한다. 숨겨진 탭과 처리·재시도 대기 중에는 자동 조회하지 않는다.

상세창은 저장된 교육 내용·지원 대상·비용 설명·회차별 일정·원문을 표시한다. 상세 API 자료가 없는 값은 생성하지 않으며 모집 미확인 표시는 유지한다. 이전 페이지의 교육 설명 버튼도 노출 이력에 있는 과정과 버전을 참조한다. 공고 선택과 역량 답변은 교육 초기 조회로 지우지 않는다.

제한: 기존 저장소의 조회 범위·세션당 1000개 탐색 제한은 유지한다. 후보 소진은 추가 조회 한 번으로 확인할 수 있다. 원문 최신 여부·지원 자격·신청 가능 여부는 기관 확인이 필요하다.

검증: 프론트엔드 57개 통과. 백엔드 501개 통과(31개 환경 의존 검사 생략). 신규 검증은 전체 조회의 모델 미호출·선택 공고 보존·빈 주제의 명시적 탐색 허용·시작일 필터·교육 목록 누적과 종료를 포함한다.

배포: 2026-11-06 코드 285e99d, backend release 20261106T001348Z 적용 Success, frontend index-DV_rysrN.js 기본 주소 HTTP 200 및 자산 일치 확인. SSO 갱신 후 배포 완료. DB 스키마 변경 없음.

상단 건수는 로딩된 카드 수가 아닌 최초 검색의 전체 후보 수를 표시하며 스크롤 추가 후에도 유지한다. 교육은 검색엔진 회차 후보 수이므로 회차 단위를 명시하고 현재 로딩된 과정 카드 수와 구분한다. 전체 건수가 없는 저장소 응답은 미집계로 표시하며 카드 수를 전체로 대체하지 않는다. 조건이 바뀐 새 검색은 새 전체 건수로 교체한다.

## 교육 상세 원문 조회

view_training 직접 요청으로 이미 표시된 교육의 source·source_id·source_version을 검증하고 DB 상세 원문을 조회한다. 목록용 500자 교육 내용·400자 지원 대상 요약 대신 저장된 전체 내용을 표시한다. 교육 내용·지원 자격·우대 대상·혜택·선발 절차·신청 유의사항·비용 안내를 구분하며 저장 값이 없으면 기관·원문 확인을 안내한다. 선택한 대표 회차 기준이며 다른 회차의 조건으로 확장하지 않는다. 시작일·마감 상태와 버전 변경을 검증하며 Bedrock 호출 및 역량 답변 변경 없음.

상세 조회 배포: 2026-11-06 코드 51cf650, backend 20261106T005532Z Success, frontend index-CJCFTqGs.js 기본 주소 파일 일치 확인. 프론트 59개·백엔드 502개 통과(31개 환경 의존 검사 생략). DB 스키마 변경 없음.

교육 상세 누락 안내: 고용24 교육 내용이 비어 있으면 “현재 연동된 API 자료에는 상세 교육 내용이 포함되어 있지 않습니다. 자세한 커리큘럼과 신청 조건은 고용24 원문 또는 교육기관에서 확인해 주세요.”로 표시한다. 정책상 수집 금지 때문이라는 확인되지 않은 원인은 표시하지 않는다. 저장 값은 그대로 표시하며 다른 출처에 API 안내를 적용하지 않는다.
