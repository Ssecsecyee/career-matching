# 통합 대시보드
상태: 구현 / 배포 전

- 왼쪽 세로 메뉴를 제거하고 상단 공고·교육·내 페이지 탭을 오른쪽 패널 전환으로 사용한다. 하나의 CareerApp과 대화 세션은 유지한다.
- 왼쪽은 AI 채팅, 오른쪽은 목록 또는 개인 기록 패널이다. 새 대화 버튼을 채팅 헤더로 이동한다.
- 경계선을 포인터 드래그 또는 키보드 좌우 화살표로 조절한다. 채팅 최소 260px·최대 680px, 오른쪽 최소 460px을 유지하도록 계산한다. Home은 기본 폭으로 복귀한다.
- 오른쪽 컨테이너가 640px 이상이면 카드 2열, 그 이하면 1열이며 3열 이상으로 늘리지 않는다.
- 데스크톱 채팅과 목록은 각각 독립 스크롤한다. 목록은 기존 무한 스크롤과 서버 정렬을 재사용한다.
- 800px 이하에서는 드래그 분할을 없애고 채팅·목록을 세로 배치한다. 저장된 스크랩·열람 내역과 서버 DB는 변경하지 않는다.
