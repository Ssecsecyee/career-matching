# Terminology sources and modifications

EDU-CARE terminology bundle v1, 2026-11-13.

Selected named-technology spellings were adapted from the Python Korea community's [python-terms](https://github.com/pythonkr/python-terms), licensed under Apache License 2.0. Original LICENSE is retained in the raw source cache. Changes: selected entries only, lowercasing, canonical/variant grouping, additional project-authored spellings, exclusion of prose definitions. Per-entry provenance is in approved.json.

Reference materials retained separately, not automatically merged into the deployed dictionary:

- Kubernetes contributors, https://kubernetes.io/ko/docs/reference/glossary/, CC BY 4.0. Heading extraction produces pending candidates only.
- MDN contributors, https://developer.mozilla.org/ko/docs/Glossary, prose CC BY-SA 2.5. Index is reference only; no automatic entry import.
- Google, https://developers.google.com/machine-learning/glossary?hl=ko, CC BY 4.0 as indicated on the page, subject to exceptions; heading extraction produces pending candidates only. https://developers.google.com/terms/site-policies
- GitHub documentation contributors, https://docs.github.com/ko/get-started/learning-about-github/github-glossary, docs repository CC BY 4.0; reference/pending candidates only.
- daangn contributors, https://github.com/daangn/search-ko-dic, MIT; original reference only, no rules selected for v1.
- Microsoft Terminology: URL reference only. Bulk data has not been downloaded or incorporated.

Raw reference copies preserve their respective licenses. They are not relicensed by this project. General source explanations and definitions are not copied into Elasticsearch synonym rules. Entries marked project are project-authored spelling mappings, not claimed as sourced from the reference dictionaries. Product names remain owned by their respective holders; attribution does not imply endorsement.
